High Cloud Airlines Analysis – Aviation Sector Insights

Project Overview:
This project focuses on analyzing flight operations in the aviation sector using data from High Cloud Airlines. The dataset includes key information such as aircraft groups, types, distance groups, carrier groups, carrier operation regions, and flight operation details. The primary goal of this analysis is to derive valuable insights into flight performance and passenger preferences through the creation of interactive dashboards.

Using Excel and Power BI, I conducted thorough data cleaning, built relationships between different data sources, and visualized the results through dashboards that address key business questions related to flight operations.

Key Analysis and Insights:

Date Field Creation and Time-Based Analysis:

Using the provided Year, Month (#), and Day fields, I created a comprehensive Date Field and derived several time-based attributes, including:
Year, Month Number, Full Month Name, Quarter (Q1-Q4), Year-Month (YYYY-MMM)
Weekday Number, Weekday Name, Financial Month, Financial Quarter

Load Factor Analysis:
The load factor, calculated as the ratio of transported passengers to available seats, was analyzed on:
Yearly, Quarterly, and Monthly basis
Carrier Name basis to compare performance across carriers
Passenger Preferences and Route Performance:

Identified the Top 10 Carriers based on passenger preference
Analyzed Top Routes based on the number of flights between city pairs
Weekend vs Weekday Performance:
A detailed analysis was conducted to compare the load factor occupancy on weekends vs weekdays, providing insights into passenger travel patterns.

Distance Group Analysis:
The number of flights was analyzed across various distance groups, providing a comprehensive understanding of how flights are distributed based on distance.

Dashboards and Visualizations:

I created a comprehensive dashboard in Excel and Power BI to present all the KPIs and insights visually.
The dashboards include key metrics such as load factors, carrier performance, top routes, and weekend-weekday comparisons.

Data Integration & Process:
The data was cleaned, integrated, and transformed using Excel functions and Power BI features. Relationships were built between the various datasets, enabling the analysis to span multiple dimensions such as carrier, distance, route, and time.

Impact and Insights:
This analysis helps airlines and stakeholders in the aviation sector understand flight operation performance across various dimensions. Key insights into load factors, carrier performance, and passenger preferences provide a data-driven foundation for optimizing operations and improving decision-making. The dashboards offer a powerful tool for visualizing these insights and supporting strategic planning in the aviation industry.
